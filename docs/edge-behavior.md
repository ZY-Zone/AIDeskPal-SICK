# 屏幕边缘行为 / Screen-edge behavior

茜特菈莉会偶尔离开桌面中央，贴着显示器边缘待机。它不是 AI 挑选的动作，
而是宿主的环境行为；AI 仍然只能从 `ai_visible` 动作里选择普通动作。

## 1. 模式

| 模式 | 位置 | 姿态 |
| --- | --- | --- |
| `side_left` / `side_right` | 双手对齐同一竖直墙线，下半身和鞋全部留在墙外；**沿竖直方向可停在任意高度** | 上半身大部分探出，只露少量裙摆下缘；面部和视线正对屏幕，左右使用独立镜像动作 |
| `top` | 双手手腕对齐上沿；**沿水平方向可停在任意位置** | 双手举过头顶扒住顶部、手距窄于肩、腿部屈膝下垂并缓慢摆荡，手指保持抓握 |
| `bottom_sit` | 按当前蒙皮支撑面对齐底边；**沿水平方向可停在任意位置** | 鸭子坐：大腿外展并外旋约 55°，小腿折回身侧，脚部自然被底边遮挡 |
| `fall` | 从顶部/侧边垂直落到底部，**保留原来的水平位置** | 短促失衡反应，末帧与落地首帧一致 |
| `land` | 从首帧接触底边开始 | 持续接触对齐，膝踝与上身缓冲，再过渡到 `bottom_sit` |

下边缘只有鸭子坐一种姿态：无论拖拽方向如何，松手吸附到底部都是 `bottom_sit`，
自动轮换也不会再选出其他底部姿态。原先的底部侧卧动作已移除。

### 沿边缘的任意位置

角色贴边后不再固定停在边缘中央：

- 用户在屏幕外拖动它并松手时，记录松手瞬间沿该边的坐标（竖边记 y、横边记 x），
  吸附时只把另一轴拉到墙线上，沿边坐标保持不变。
- 自动换姿势时沿用同一坐标，因此它会在同一条边上待在用户放下的位置附近。
- 坐标按轴向记账：侧边的 y 绝不会被当成底边/顶边的 x 复用，避免掉落时突然横跳。
- 坐标会被约束在屏幕范围内，保证角色始终有一部分可被鼠标点到，不会彻底消失。
- 只有首次进入某条边（没有任何记录）时才在可用区间内随机取一个自然位置。

模型旋转由渲染器的 `stage_roll_degrees` / `stage_yaw_degrees` 完成，
**不旋转操作系统窗口**，所以透明区域、DPI、点击穿透和 alpha mask 都保持原逻辑。
坐姿只用普通骨骼 `左足` / `左ひざ` / `左足首`；渲染器会评估 PMX 的追加变换，
所以不能再同时驱动 `左足D` 等变形骨，否则同一关节会被写两次。边缘姿态全部使用常规窗口尺寸，
不再有需要加宽窗口的横躺姿态。

接触定位不是固定窗口比例：坐姿和落地采样当前动作的真实蒙皮顶点，侧挂/上挂采样
对应手腕骨骼，再通过同一相机投影换算为窗口坐标。`animation_advanced` 在每次角色时钟
推进后触发约束更新，避免快速落地时窗口追赶上一帧；低频计时器仅作兜底。旋转、朝向、
缩放和窗口宽高共用缓动时间线，进入和退出都不会瞬时切换。

上挂的手腕与坐姿腿部的角度都是实测值，不是估计值：手距由 FK 搜索确定（腕 Z=115°/Y=-5°，
手腕停在 x≈±1.1、略高于头顶）；鸭子坐取大腿外展 30°、外旋 55°，实测膝盖 x≈4.49、
脚踝 x≈4.67，小腿真正折向身侧。这些数字由作者的 FK 求解脚本与实机抓帧工具共同确定
（工具不随仓库发布），改动这些角度前应先重新测量。

## 2. 触发节奏

- 设置 → 角色与动作 → 窗口与显示 → **启用屏幕边缘行为**
- 默认启动约 7 秒后第一次选择边缘；之后每 32–130 秒左右换一个位置
- **拖动阈值**：拖动松手后，用 framebuffer alpha mask 估算实际角色内容 bbox；
  只要有 20% 以上的角色内容出界（即屏幕内不足 80%），就按最近边自动吸附到
  `side_left` / `side_right` / `top` / 底部鸭子坐；
  下边缘固定为鸭子坐，与拖拽方向无关
- 顶部/侧边停留后会按 `edge_fall_chance`（默认 0.4）在 9–23 秒内尝试掉落
- 掉落是窗口位置动画（InCubic），同时播放 `edge_fall`；落地播放
  `edge_land_sit`，随后接 `edge_bottom_sit`
- 拖动、点击互动、托盘选动作或调整缩放会中断边缘状态，避免卡在半空

## 3. 动作与资源

这些动作放在 `actions/citlali_summer/edge/`，`ai_visible=false`，不会进入 AI 动作目录：

- `edge_side_hang`
- `edge_side_hang_right`（由左侧最终姿态严格镜像生成）
- `edge_top_grip`
- `edge_bottom_sit`
- `edge_fall`
- `edge_land_sit`

这些动作由作者的动作生成脚本批量产出并做统一收尾（落地衔接、鸭子坐、上挂手距、手型、
跳跃和衣物跟随），重复生成结果一致；脚本不随仓库发布，二次开发者按
`docs/action-authoring.md` 的格式自行制作即可。

## 4. 限制

- 仅当模型动作库包含全部 7 个 `edge_*` 动作时启用；其他模型不会触发。
- 双屏切换以窗口中心所在屏幕为准；大部分窗口移出屏幕后可能回退到主屏。
- 窗口被移出屏幕是设计的一部分；如果找不到宠物，可在托盘菜单选择「显示桌宠」，
  或关闭边缘行为。
